## Como usar

1. Instale as dependencias:

```bash
npm install
```

2. Rode os testes:

```bash
npm test
```

3. Escolha um teste em `__tests__/exercises.test.js`.
4. Implemente a funcao correspondente em `src/exercises.js`.
5. Rode os testes de novo ate passar.

## Comandos uteis

```bash
npm run test:medium
```
